# Aman-Anand-demp
A continuous, command-line interface (CLI) calculator built using Python. This is my very first mini-project, created to practice core programming fundamentals, user input validation, and loop control structures.

## 🚀 Features

- **Four Basic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Input Validation:** Automatically detects invalid operator inputs and prompts the user to try again.
- **Zero-Division Protection:** Prevents system crashes by explicitly checking for and blocking division by zero.
- **Infinite Loop Execution:** Uses a `while True` loop so you can perform multiple calculations seamlessly without restarting the program.

## 🛠️ Concepts Practiced

- **Control Flow:** Utilizing `if-elif-else` conditional blocks to route arithmetic operations.
- **Loops & Iteration:** Implementing `while True` and `continue` statements to manage execution flow.
- **Data Collections:** Using a Python `list` to store and validate acceptable mathematical operators.
- **Data Type Casting:** Converting string inputs into floating-point numbers (`float`) to allow decimal calculations.
